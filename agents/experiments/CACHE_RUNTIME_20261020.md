Training use_cache=false remains; generation use_cache=true is an intra-generation KV cache and does not persist after child exit.

Strengthened GPU guard: capture original idle session baseline, require every model child to start AND finish with free VRAM back within256MiB of that original baseline. External GPU consumers/driver problems or a new model's true capacity can still fail; do not claim every OOM is prevented.
