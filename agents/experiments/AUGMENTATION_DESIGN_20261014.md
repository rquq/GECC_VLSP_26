# Kaggle augmentation branch design

The user requested a separate branch dedicated to creating a new dataset from the approved full-training dataset (585 classifier /495 corrector, including all81 former local validation rows). Branch: kaggle-augment, based on030cb13. Reuse the existing source checkout/environment/subprocess notebook launcher, with committed choices and no notebook toggles. The user delegates pipeline and budget decisions; implement inline without repeating design/plan approval questions.

Use up to96 original parent references in the intersection of classifier/corrector retained originals. Exclude incomplete/annotation targets as generation seeds, preserving every baseline row in output. Translate reviewed complete references Vietnamese→English/Chinese→Vietnamese with pinned Hy-MT2-7B. Generate two distinct proposed taxonomy errors per novel return using pinned Qwen2.5-7B-Instruct. Review parent/return semantics and cleanliness and independently infer candidate label/correction with pinned Sailor-7B-Chat, hiding the requested error label/mechanism. Mechanical span/lexical/number/minimality gates and cross-model evidence are mandatory; model agreement alone is not human verification.

Accepted error caps: label1=24, label2=64, label3=64, label4=48. Add one clean control per unique accepted reference. Total at most200 errors +200 clean controls, so classifier<=985/corrector<=895. Caps per mechanism=ceil(class quota/6), at most4 accepted errors per original parent and2 per translated reference. Seed42; two pivots; at most1344 inference calls and360 wall minutes. No filler or minimum quota, no classifier/corrector training and no official test input reads. Empty acceptance is recorded explicitly.

Each causal model must pass native unique-parameter audits before loading and after dispatch. Preserve Hy's tied embedding/head; use FP16 inference with explicit contiguous two-T4 placement, tied head on embedding GPU and no offload. Stages are sequential and release weights/cache before the next. Store one transient model download cache outside Kaggle working outputs, deleting it at stage transitions. Generation requires Transformers5.6.0 in an isolated environment, preserving CUDA Torch. Publishers' model revisions/native counts/licenses are recorded.

Persist input/config/source fingerprints, each prompt/output/settings/digest, parent IDs, mechanisms, patches, clean review and blind error review, rejections and source-family IDs privately. Checkpoint every call; a CLI resume of an unchanged run reuses the journal and preserves call/time limits. Cache mismatch/tampering is rejected. Automatic budget exhaustion exports only completed accepted pairs. Unexpected runtime failures retain an explicit failed manifest and diagnostics.

Export VGEC26-augmented-full-training.zip with canonical original/classifier/corrector files, raw training arrays, manifest and audit. Synthetic full-training bundles use vgec-augmented-final-v1: embedded verified baseline, original585/495 prefix preserved, then exact accepted machine-reviewed additions and empty validation. Strict loaders revalidate baseline, evidence, caps, typed IDs and membership. No score improvement or human adjudication is claimed. The separate training branch needs a deliberate consumer/hash update before training on this new format; augmentation never mutates its recipe or baseline files.

Verify failing→passing tests for seed selection, independent review gates, single-span reconstruction/taxonomy constraints, duplicates/caps, append-only baseline preservation, journal/resume/budgets, native/tied placement, ZIP discovery and notebook output.
